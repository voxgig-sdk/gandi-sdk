API

LivednsKey

A zone's DNSSEC keys on LiveDNS: list, create, get, undelete (update) or delete one.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /livedns/domains/{fqdn}/keys create Created
GET /livedns/domains/{fqdn}/keys list OK
GET /livedns/domains/{fqdn}/keys/{id} load OK
DELETE /livedns/domains/{fqdn}/keys/{id} remove No Content
PATCH /livedns/domains/{fqdn}/keys/{id} update OK
