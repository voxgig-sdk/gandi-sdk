API

DomainTransfer

A transfer of a domain to Gandi: start it, follow it, relaunch it, update its authorization code (authinfo), check it is possible (available) or resend its emails (foa).

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns

POST /domain/transferin/{domain}/foa create Accepted
POST /domain/transferin create OK
GET /domain/transferin/{domain} load OK
PUT /domain/transferin/{domain} update Accepted
PUT /domain/transferin/{domain}/authinfo update Accepted
